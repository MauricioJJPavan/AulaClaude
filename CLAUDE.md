# CLAUDE

Objetivo: pasta de estudos para aprender a usar o Claude Code criando pequenos projetos de exemplo.

Stack:
- Python
- Streamlit
- yfinance
- Plotly
- pandas

Convenções:
- Cada projeto fica em sua própria subpasta.
- Cada projeto deve conter `app.py`, `requirements.txt` e `README.md`.
- Sempre criar `.venv` antes de instalar dependências.
- Sempre criar `requirements.txt` com as dependências do projeto.

Comportamento esperado do Claude:
- Sempre perguntar antes de instalar pacotes.
- Sempre criar o `.venv` antes de qualquer instalação.
- Sempre explicar o que está fazendo em português.
- Sempre fazer commits ao final de cada etapa concluída.
